### S02 增肌蛋白質：學會原文

[ISSN 2017 立場文件](https://link.springer.com/article/10.1186/s12970-017-0177-8)對健康運動者列 1.4–2.0 g/kg/day。1.6 為範圍內的產品候選值，並非學會指定唯一預設。選「增肌」本身不等於已有阻力訓練。

### S03 增肌熱量：原始試驗

[Helms 等 2023](https://link.springer.com/article/10.1186/s40798-023-00651-y)比較維持、5%、15% 盈餘，17 人完成，研究對象有阻力訓練經驗。研究支持避免較大盈餘造成額外脂肪增加；+5% 是保守產品候選，不能稱所有成人最佳值。該研究蛋白質安排也不是 1.6，不能稱本案兩個參數的組合完整重現該試驗。

### S04 減脂熱量：國健署原文

[國健署健康職場資訊網](https://health.hpa.gov.tw/hpa/info/print.aspx?enc=ms8UXTGwISDdpLhTR1JPDA%3D%3D)體重管理說明列每日減少攝取 500 kcal，或飲食減少 300 加活動消耗 200，並列每日熱量不可低於 1200。本文以肥胖管理為背景，不能宣稱所有正常體重成人都適用。其 BMI 分類為 ≥24 過重、≥27 肥胖。

產品候選只扣飲食 500，不假裝系統已量測額外運動消耗。低於 1200 時回報不適用、不自動夾到 1200，為待確認的處理行為；高於下限也不代表已證明適合每個人。

### S05 減脂蛋白質：原始試驗與補充證據

[Evans 等 2012](https://link.springer.com/article/10.1186/1743-7075-9-55)涵蓋 40–56 歲、BMI ≥26 的成人，130 人，處方約 1.6 g/kg/day 並減少約 500 kcal。直接證據不等於需求應限定為該年齡帶。

新增查證：[Pasiakos 等 2013 原始試驗摘要](https://pubmed.ncbi.nlm.nih.gov/23739654/)比較 0.8、1.6、2.4 g/kg/day，39 人，在短期 40% 能量缺口下，較高蛋白組去脂體重流失比例較少。它補強能量不足下保存去脂體重的依據，但不是本案 −500 kcal 的同一套介入，不能據此證明所有高齡或正常 BMI 族群的長期效果。

[Leidy 等 2015 綜述摘要](https://pubmed.ncbi.nlm.nih.gov/25926512/)整理 1.2–1.6 g/kg/day 的體重管理研究，長期結果有不一致與依從性限制。此為補充綜述，不當作單一原始試驗。綜合來源可支持 1.6 作候選，仍沒有「所有 19 歲以上健康成人統一處方」的直接證明。

本次沒有找到可讓使用者不需適用條件、直接使用一套增減參數的第一手依據。Q3 需明確核准外推與產品邊界；不得自行取消一般健康成人目標需求。

## 3. 每日熱量候選契約

### 成人：衛公式－1與臺灣 PAL

`A` 為足歲、`W` 為目前體重 kg、`S` 為原公式性別分支（男=1、女=0）。

```text
RMR_per_kg = 28.2437 + 2.4275×S − 0.02277×A − 0.1234×W
REE = RMR_per_kg × W
E0 = REE × PAL
```

| 活動類別 | PAL |
|---|---:|
| sedentary／低 | 1.3 |
| low_active／稍低 | 1.5 |
| active／適度 | 1.7 |
| highly_active／高 | 1.9 |

這個組合依成人熱量章節公式及表三／四，使用個人年齡與體重計算；將類別平均 PAL 作個人預設為產品選型，需 Q1 確認。`E0` 已是每日總量估計，不再疊乘活動倍率，也不另加一次食物熱效應。衛公式－1不使用身高；身高僅可能供減脂 BMI 條件使用，不能為成人維持基準強制要求無關欄位。

活動由使用者選，不從目標或職稱推測、不默認 sedentary。日常活動說明需對照原文案例，不把每週運動次數直接等同 PAL。

## 5. n 倍與當餐目標：沿用核准契約

T03 的每日基準計算不使用 n，不將體重乘 n、不用 n 推估年齡或活動、不以 n 再次調整增肌／減脂參數。每日基準在服務輸出中保持未縮放狀態。

對每個用餐／便當項目 j：

```text
r(j) = 早餐 0.30／午餐 0.30／晚餐 0.40
B_E(j) = D_E(j) × r(j)
B_P(j) = D_P(j) × r(j)
N = Σ n(j)
E_target = Σ [B_E(j) × n(j)]
P_target = Σ [B_P(j) × n(j)]
E_reference = E_target / N
P_reference = P_target / N
```

- 成員 n 僅接受 `0.7, 0.85, 1, 1.15, 1.3`，總 N 不限這五個值。
- 同一成員吃晚餐又帶午餐便當，是兩個項目，各乘一次相應餐別比例及 n。
- 先將基準配方對齊合成基準各自 ±10%，再乘 N，最後以同步縮放目標驗證。T12 負責配方及營養驗證，T03 不生成食譜。
- 兒少的個人公式已反映年齡；按 Spec 再乘 n 是額外的食量規劃選擇，不能自動把兒少年齡換成 0.7n，也不能除以 n 抵銷使用者選擇。
- n 縮放後的值稱當餐規劃目標；不是公式證明的個人每日攝取建議。全家合計通過不代表每位成員實際攝取已達標。
- 原始數值用 Decimal 計算與保存；只在顯示時取整，不將顯示數值帶回驗證。

| 情境 | 行為 |
|---|---|
| n 是五個允許值 | 接受；0.69、0.9、1.31、NaN、Infinity、布林拒絕 |
| 兩個1.3n，N=2.6 | 合計合法，不把五段限制套到總N |
| 足歲<3 | 已核准首版不支援，不用3歲規則外推 |
| 足歲3／4／7／10／13／16／19 | 分支邊界，按足歲選表；19進成人式 |
| 足歲18增肌／減脂 | 已核准首版不支援；不能稱18歲一定是未成年 |
| 3–15歲選低／高活動 | Q1候選回報不支援，不默默改稍低或適度 |
| 足歲69／70／71維持、W=60 | Q2候選蛋白質66／72／72g；待確認後才測正式程式 |
| 無年齡、體重、活動或公式性別 | 回報缺必要輸入，不代填 |
| 成人維持／增肌無身高 | 衛公式－1不需要身高；減脂BMI條件另判必要輸入 |
| 體重≤0、非有限數值、布林 | INVALID_INPUT |
| 成人算式RMR≤0、或超出已驗證體位範圍 | 回報不適用；研究支援上下限待補，不能猜數值 |
| 增肌未確認訓練條件 | Q3候選回報不適用，不改成維持 |
| 減脂BMI<24 | Q3候選回報不適用，是否含正常BMI待使用者確認 |
| E0−500=1200／1199.99 | Q3候選前者僅下限條件通過；後者不支援，不自動夾值 |
| 孕期／哺乳期／治療飲食 | 一般規則不適用；確認欄位待定，不收集完整診斷紀錄 |
| 規則版本未知／未核准／必要來源未驗證 | 不回傳可供正式採用的假目標 |
| 目標780／39，營養702／35.1或858／42.9 | ±10%含上下界；T12責任 |
| 熱量701.999或蛋白質42.9001 | 超界不可採用，不因顯示取整通過 |

年齡建議使用生日與餐食日期算足歲並保存快照，避免只存當前年齡造成歷史重算漂移；不為缺生日者猜生日。若上游只提供足歲，保存該值與計算日期及輸入版本。

錯誤理由建議放在既有 `INVALID_INPUT` details；`UNSUPPORTED_TARGET_SCOPE`、`TARGET_RULE_UNVERIFIED`、`REQUIRED_TARGET_INPUT_MISSING` 為待協調的細分理由，不宣稱已定版 API 新碼。

## 8. 隊友交接介面草案

T03 交付版本化 Python `NutritionTargetService`；不擴張T07登入／家庭CRUD、T08問卷或T12配方調整。T07保存必要輸入與n，T08組參與項目，T12消費每日基準並組當餐目標。

- 全部計算：成員ID、足歲或生日及餐食日期、原公式性別分支、體重kg、活動類別、目標、規則版本及一般健康適用性確認。
- 成人衛公式－1：不要求身高。若減脂以BMI判適用性，另須身高cm。
- 增肌：另須訓練條件確認；不能從目標推論。
- n：成員／參與項目欄位，可驗證五段，但不進每日基準縮放。
- 來源、係數、輸入版本與計算日期須保留快照，Log不寫姓名及完整身體／健康資料。
