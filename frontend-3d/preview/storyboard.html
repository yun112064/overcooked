🏠 今天吃啥・場景式前端分鏡

整個 App 是一間家。使用者在同一個房子裡移動，而不是切換頁面：相機隨滑鼠／陀螺儀微調視角，導覽就是鏡頭從客廳推進廚房、轉到餐桌、走到冰箱、回頭看牆上的全家福。每格分鏡可移動滑鼠看視差分層。資料是假的，插圖是示意用的簡單幾何，正式版會換成分層插畫。

鏡頭地圖：一間房子，從大門進來後六個停靠點

分鏡 0
相機：站在門外 → 進門後站在玄關景深：街景/牆 → 門/鞋櫃 → 名牌卡/門牌 → 提示

大門與玄關

/login　→　/households
大門
門上掛一張名牌卡＝登入表單，翻面是註冊。錯誤時名牌輕晃，欄位下同時有文字錯誤。登入成功大門打開，鏡頭走進玄關。
玄關
鞋櫃上方一排門牌，每張＝一個家庭（名稱、成員頭像，上次使用的那張有標記）。虛線空位＝建立新家庭。選好後內門打開，鏡頭推進客廳（分鏡 1）。
登出
從全家福設定列登出 → 鏡頭一路退回門外。
資料
POST /auth/login、/auth/register、GET /auth/me；GET /household、POST /household、POST /household/select。
手機
大門與玄關各佔一屏，不並排。
分鏡 1
相機：沙發正前方，±4° 隨滑鼠景深：窗/畫/廚房門口 → 沙發/電視 → 茶几餐盤（擺飾） → 小幫手

今日・客廳

/today　首頁一天多餐
場景
坐在沙發上看客廳。右邊是廚房門口，透過門看得到爐台的鍋；牆上是全家福；電視播近 7 天熱量趨勢。茶几上的餐盤只是今天餐單的擺飾，不可點。
入口
  • 廚房門口 → 鏡頭走進廚房（分鏡 2）；有生成在跑時門口會看到鍋子冒蒸氣
  • 全家福 → 分鏡 6
  • 電視 → 切換早／午／晚，螢幕上的趨勢跟著換；餐盤同步換菜
一鍵購入
移出茶几，放到進廚房之後的餐桌（分鏡 4）與冰箱便利貼上，客廳不做動作。
資料
GET /meal-plans（今日各餐）、/meal-plans/trend、GET /jobs（門口蒸氣）。
分鏡 2
相機：站在廚房中央，略俯視爐台景深：磁磚/出菜口/冰箱 → 單軌/便利貼/台面 → 瓦斯爐上的鍋/食譜書 → 小幫手

規劃・廚房全景

/plan
場景
四個入口，各在自己的位置：
  • 左上・出菜口＋單軌：掛著的單＝既有問卷（草稿、生成中、待決定），點單接續那份 → 分鏡 3。
  • 中央・檯面上的瓦斯爐：雙口爐平放在流理台上，鍋坐在左爐口；點空鍋＝新的一餐 → 分鏡 3；鍋裡有東西就是進行中的那份。
  • 右・冰箱門：貼滿便利貼（最近餐單、本週採購、月曆），點任一張 → 分鏡 5。
  • 左下・闔上的精裝食譜書：書口露出分類書籤標籤與紅緞帶，翻開 → 分鏡 2b。
兩口爐
左爐口的鍋代表最新一份；同時還有另一份在生成時，右爐口也出現一口蓋著冒煙的鍋，點了進那一份的分鏡 3。第三份以上只掛在單軌。
鍋的狀態
空鍋：沒有工作。裝料未蓋：有草稿。蓋著冒蒸氣：生成中（點了進分鏡 3 看進度）。蓋子開、全亮：結果出來了，點了去餐桌（分鏡 4）。
資料
GET /meal-requests（單軌）、GET /jobs（鍋）、GET /meal-plans（便利貼）。
分鏡 2b
相機：俯視台面上攤開的書，±4°景深：台面 → 書頁 → 清單/細節/托盤 → 書籤

食譜庫・翻開的食譜書

/pick　/pick/:id
場景
廚房台面上那本綠皮書翻開：左頁是條列清單（一頁 10 道，翻頁換下一批），右頁是點到的那道的細節。右側書籤＝分類篩選，頁首可手寫搜尋。
選菜
點清單任一列 → 右頁翻到細節 → 「夾進托盤」。托盤像壓在書上的紙鎮，裝滿後「送去出菜口」＝帶著這些食譜開新單（分鏡 3），或塞進既有的單（/pick/:id）。
辨識
「拍冰箱」是捷徑：帶著托盤裡的食譜開單，直接跳到分鏡 3 第 3 步的相機框。辨識流程只有那一套。
資料
GET …/recipe-catalog、POST /assistant/recipes、POST /recognitions；營養缺值一律「未知」。
手機
一次只看一頁：左右滑＝翻頁，書籤收在右緣可拉出；托盤固定在底部。
分鏡 3
相機：抬頭看出菜口單板，再低頭看爐台，兩者同框景深：牆/爐台 → 單板/鍋 → 入鍋的料 → 提示

問卷・左單板，右鍋子

/plan/:id　→ 送出後 /plan/:id/cooking
版面
左邊是出菜口的點菜單板（問卷五步），右邊是爐台上那口鍋的俯視圖。從分鏡 2 點空鍋進來是新的一餐；點單軌上的單進來則是接續那份（鍋裡已有前幾步的料）。
鍋隨步驟變化
鍋統一是火鍋外觀，沒有主食；每一步加入的元素固定，與使用者填什麼無關：
  • 步驟 1 日期餐別、預算 → 🥬 菜
  • 步驟 2 成員 → 🍄 菇類
  • 步驟 3 現有食材辨識 → 🍗 肉
  • 步驟 4 主食偏好與不吃的 → 🍲 湯（湯底漲滿）
  • 步驟 5 確認（營養預覽）→ 🥚🍅🌽 配菜補滿，鍋全滿、鍋緣亮
食物只是進度示意，不代表實際生成的菜。
步驟 3 辨識
單板上開相機框拍冰箱或檯面，辨識到的食材以 chip 列出逐項確認，低信心加「?」，可手動補、也可整步略過（鍋裡的肉照樣掉進去）。確認的食材送進生成作為「現有食材」。分鏡 2b 食譜書與分鏡 5 冰箱的「拍冰箱」都是進到這一步的捷徑。POST /recognitions、POST /recognitions/:id/confirm。
送出
按「開始煮」：鍋蓋蓋上、冒熱氣、單板滑回單軌，鏡頭留在鍋上（分鏡 3b）。真實工作狀態點在鍋蓋旁：已收到 → 排隊 → 計算營養 → 查價 → 完成。可取消（掀蓋、料還在、回單板）。
完成
鍋蓋打開、整鍋全亮，鏡頭轉到餐桌（分鏡 4）。失敗：鍋蓋半開冒黑煙，顯示原因與重試。
手機
上下分：上半是鍋（縮小），下半是單板一步一屏；鍋可往上收起只留鍋緣。
分鏡 3b
同一口鍋的五個狀態；分鏡 2 的鍋也照這套顯示目前進度

鍋的狀態機

/plan（分鏡 2 的鍋）、/plan/:id、/plan/:id/cooking
對應
①無工作／②草稿／③待送出／④`queued`、`running`／⑤`succeeded`（失敗：蓋半開冒黑煙＋重試）。
外觀
五態統一為火鍋，沒有主食。入鍋元素固定：①日期餐別、預算→菜 ②成員→菇 ③食材辨識→肉 ④偏好→湯 ⑤確認→配菜補滿，不隨使用者的選項改變。
原則
④只用後端回報的階段點亮，不顯示假百分比；取消＝掀蓋，料保留在鍋裡（草稿不丟）。
分鏡 4
相機：從爐台轉身到餐桌，俯角 30°景深：吊燈/牆 → 桌面 → 飯鍋/菜盤/湯鍋/飯碗/收據 → 動作列

結果・餐桌（一桌菜）

/plan/:id/result/:ver
場景
台式合菜擺法：餐單裡有幾道菜，桌上就有幾個盤子，依類型用不同器皿——主食是飯鍋（標份數）、肉／海鮮和蔬菜各一個菜盤、湯是湯鍋冒蒸氣。每位成員座位前一個飯碗＝個人營養判定。
花費
一張超市收據壓在菜盤邊：第一行「要買的整包 $486」、第二行「這餐吃掉 $312」、底下蓋「預算內」章；價格未知的食材在收據上列出。點收據展開每項食材明細。
互動
  • 點任一盤 → 盤子抬起，翻出做法與食材
  • 點飯碗 → 展開個人營養表（平面表格）
  • 「換一桌」→ 收盤、回爐台重新備料；「採用這桌」→ 蓋章，鏡頭回客廳茶几
營養小知識
桌上一個小卡盤放著一疊知識卡，每張是這桌其中一樣食材的小知識（例如「番茄加熱後茄紅素更好吸收」），來源固定印在卡片上並可連到原文。點卡盤一張張翻看。
  • 服務暫時無法使用或額度不足 → 卡盤是空的，寫明原因，提供「只重試小知識」；菜單與採用不受影響
  • 這桌的食材查不到小知識 → 空卡盤加一句說明，不顯示重試、不拿別的內容充數
  • 重試中 → 顯示進行中，完成後換成新版本
規則
熱量 ≤110%、蛋白質 ≥90% 三態；缺值的碗虛線加「未知」，不畫食物。整包／比例金額分兩行，不相加。
分鏡 5
相機：平視冰箱門，±5°景深：牆 → 冰箱門 → 磁鐵貼紙 → 分頁磁鐵

紀錄・冰箱門

/records?tab=adopted ｜ ?tab=nutrition
場景
家裡冰箱門上貼滿東西：月曆（有餐盤貼紙的日子表示有採用餐單）、便利貼（當日餐單）、採購金額長條、生成紀錄清單。磁鐵就是分頁切換。
互動
  • 點月曆日期 → 便利貼換成那天的餐單
  • 點便利貼 → 鏡頭轉到餐桌（分鏡 4）重看那份餐單（唯讀快照，不可改）
  • 拉開冰箱門（上滑把手）→ 捷徑到分鏡 3 第 3 步的相機框：拍冰箱裡有什麼
資料
GET /meal-plans、/meal-plans/trend；歷史快照只讀。
分鏡 6
相機：從沙發回頭仰看牆面，±5°景深：壁紙 → 畫框 → 蠟筆人物 → 設定列

家庭・牆上的全家福

/family
場景
客廳牆上一張「小孩蠟筆畫」風格的全家福，每個人物就是一位成員。畫框下緣是設定列（景深效果、家庭切換、服務狀態、登出）。
互動
  • 點人物 → 人物從畫裡走出來放大，顯示年齡、活動量、個人目標摘要；編輯用一張「蠟筆便條」對話框
  • 虛線空位「畫上新成員」→ 新增成員
  • 未填欄位在畫上用鉛筆底線標示，不猜值
風格
人物為蠟筆筆觸（粗邊、不均勻填色、略歪），與其他場景的乾淨幾何形成對比，暗示「這是孩子畫的」。

鏡頭轉場規則（草案）：同一房間內的停靠點用「平移＋微轉」（0.4 s）；跨房間用「推進＋景深模糊」（0.6 s）；底部分頁／側欄點擊一律用最短路徑。手機以陀螺儀代替滑鼠微調視角（需使用者點一次授權），拒絕則用拖曳。靜態景深模式保留所有場景與分層，但鏡頭不動、轉場改為淡入淡出；關閉模式則退回卡片版面（前一版 index.html）。
