# 05 — YOLO 蔬菜辨識模型與獨立評估

- Spec：`../spec.md`
- Blocked by：無
- 覆蓋：R03、G05 辨識部分；AC22、AC28
- 狀態：使用者已核准本次拆分及後續修正；尚未實作。

## 交付成果

交付可載入的蔬菜辨識模型、固定類別／前後處理版本及獨立品質報告。

## 驗收條件

- 以相同資料比較 YOLOv8n 與 v8m，依來源分開訓練／驗證／保留測試，防止相近照片跨集合；記錄資料來源及權重版本。
- 獨立測試集主要類別 macro precision／recall 各至少 80%，採 IoU≥0.5 一對一配對；另報 mAP50、mAP50–95、各類樣本數及延遲，不計人工修正。
- 內部保留類別、位置、信心及版本供模型評估；對使用者列出所有有效辨識到的蔬菜名稱填入文字框，不輸出重量。AC22 評估仍用偵測結果，不能用文字框修正後答案計分。團隊電腦推論及跨節點容量留待 Ticket 18 驗證。
