# 07 — 登入、家庭及成員設定完整流程

- Spec：`../spec.md`
- Blocked by：03 — 家庭成員營養目標規則定版；06 — 可啟動系統骨架與正式日誌

## 交付成果

使用者可註冊、登入、登出，建立／選擇授權家庭並維護成員資料。

## 驗收條件

- 使用 Argon2 及 Secure／HttpOnly Cookie session，狀態修改具 CSRF／Origin 檢查；跨家庭資料讀寫遭拒。
- 表單包含規則所需輸入、目標、過敏／禁吃與 n；前後端均只接受五段 n，未成年不能選增肌／減脂。
- 成員是被規劃資料而非必須另建帳號；設定可保存重讀，錯誤明確可修正。提供 API 與實際頁面流程驗證。
