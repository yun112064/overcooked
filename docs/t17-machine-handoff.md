## 實機操作與判定

各項目前均為 **待執行**，需另附實際證據才可標記通過。執行前先確認拿到含修正的版本，並閱讀 [還原操作與舊備份限制](t17-backup-recovery.md)。

| 驗收項目 | 操作與通過條件 | 證據 |
| --- | --- | --- |
| 啟動與重啟 | 在目標 Windows 電腦執行 `scripts/prod-up.ps1`；容器、schema gate 與前端健康檢查正常；重跑與重啟不誤用開發庫 | 提交 SHA、去除秘密的腳本輸出與容器狀態 |
| YOLO／Ollama／TEI | 辨識與小幫手能正常操作；服務離線有不可用狀態，恢復後可重試；記錄 GPU 記憶體 | 測試步驟、服務狀態、GPU 使用量 |
| 外網與串流 | 從另一個網路存取快速通道；註冊／登入／家庭操作正常，小幫手 POST 串流逐段抵達 | 去除私人內容的操作紀錄、時間戳、HTTP 狀態 |
| 每日備份與獨立副本 | 用更新後程式備份業務／知識／小幫手三庫；本地與鏡像 manifest／checksum 一致 | 三份備份時間、獨立副本位置與核驗結果 |
| 真實部署環境的還原演練 | 只還原至新的演練庫與空目錄；驗證版本／筆數／照片／索引；使用原受限 app 帳號驗證登入、家庭與餐食讀寫 | 還原報告、app 帳號操作結果；不得以 postgres 成功代替 app 驗證 |
| Windows 工作排程 | 確認備份時間、執行帳號、獨立磁碟權限；註冊後檢查結果碼及錯過後補跑 | 工作排程狀態與去除秘密的備份日誌 |

演練期間保留原庫與正式連線，使用臨時設定連到演練庫，不直接切換正式 DATABASE_URL。若需檔案與資料庫完全一致，安排維護時間停止相關寫入後再備份。演練庫清理由該同學確認名稱後執行。
