# T03 MVP 營養規則與來源紀錄

日期：2026-10-05。現行規則版本：`hpa-dri8-mvp-0.2.0`。

## 使用者定案

- 本次先交付 T03，T08、T15 等待隊友相依功能。
- MVP 所有年齡先套成人標準；兒少專用公式及條件於 MVP 後加入。
- 熱量使用國健署衛公式－1及臺灣官方活動係數。
- 一般餐食與維持：不調整每日能量 E0。
- 增肌：E0×1.05。減脂：E0−500 kcal；低於1200 kcal回報不適用，不自動夾值或改成維持。
- **全部年齡與全部目標的蛋白質都用目前體重×1.1 g/kg/day**；不用1.6，不加入70歲切換。
- 不自行加 BMI、訓練或兒少年齡門檻；這些適用條件依使用者 MVP 指示延後。
- n 僅五段，個人每日基準不乘n。早餐／午餐／晚餐比例為0.3／0.3／0.4。每個用餐或便當項目各縮放一次，再合計。

## 可追溯來源

1. [使用者指定國健署 DRIs 專區](https://www.hpa.gov.tw/Pages/Detail.aspx?id=549&nodeid=4248&pid=12285)。入口讀取失敗，成人公式與 PAL、一般蛋白質已核對國健署出版全文的解析文字。第八版2023-12，ISBN `978-626-7260-78-4`，印刷頁37–41、116–117；[學校網域保存的全文鏡像](https://www.ccjhs.tp.edu.tw/wp-content/uploads/doc/c004/%E5%9C%8B%E4%BA%BA%E8%86%B3%E9%A3%9F%E7%87%9F%E9%A4%8A%E7%B4%A0%E5%8F%83%E8%80%83%E6%94%9D%E5%8F%96%E9%87%8F%E5%8F%8A%E5%85%B6%E8%AA%AA%E6%98%8E.pdf)可讀。出版者為國健署，學校只是託管；不能稱已從原站下載來源檔。
2. [國健署體重管理說明](https://health.hpa.gov.tw/hpa/info/print.aspx?enc=ms8UXTGwISDdpLhTR1JPDA%3D%3D)：飲食減少500 kcal及每日不可低於1200的依據，原說明以肥胖管理為背景。
3. [Helms 等2023原始試驗](https://link.springer.com/article/10.1186/s40798-023-00651-y)：有阻力訓練者的能量盈餘比較，+5%為本案經使用者選定的產品參數，不稱所有年齡的唯一官方最佳值。

蛋白質1.1、成人公式及活動係數的來源，與 MVP 全部年齡統一套用的產品決策分開保存。原成人能量章適用19歲以上；高齡蛋白質與兒少係數原本不同，產品簡化不表示來源已驗證全部年齡。也不能把食譜±10%容差當個人能量公式的準確率。

本次固定第八版，不稱它為2026-10-05最新版。PDF視覺核對與本地來源檔保存尚未完成，規則設定SHA-256不是官方PDF雜湊。

## G03結論

MVP計算選型已由使用者確認，程式與人工算術可供隊友接入測試。**G03整體尚未通過**：來源PDF視覺核對與檔案保存仍待完成，且成人式外推至所有年齡是產品簡化而非官方適用性驗證。

因此輸出 `daily_target_available=true` 表示已能計算完整數值；`approved_for_adoption=false` 保留資料前置驗證狀態。它不能替代T12的營養完整性、±10%及其他採用條件。Ticket不標整體驗收完成。
